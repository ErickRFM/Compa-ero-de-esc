# UI V5 visual QA

Reference surfaces:

- Login
- First access / registration
- Hoy
- Agenda
- Asistencia alumno
- Scanner
- Avisos
- Perfil
- Pase docente

For each surface classify differences as:

- A — matches: do not touch;
- B — minor difference: refine;
- C — missing visual component: complete;
- D — missing product/domain behavior: separate functional work.

Review:

- hierarchy;
- spacing and padding;
- card proportions;
- typography scale;
- crimson/graphite/warm-surface balance;
- semantic-state color;
- headers and safe areas;
- floating bottom dock;
- scanner overlay;
- compact/medium/expanded layouts.

Functional regressions block visual approval.
