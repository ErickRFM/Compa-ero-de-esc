# V10.1 — lectura PDF acotada y cancelación

Auditoría del importador ya integrado por #112. Base del lector: main `0ac109118e87740872b6275dc8f6836047115a0a`. No reemplaza el parser, la geometría de glifos ni el fallback OCR.

## Correcciones

El lector nativo usaba readBytes() antes de comprobar sus 12 MB: un stream arbitrariamente grande podía consumirse completo. Ahora consume como máximo el límite más un byte para detectar exceso, conserva archivos de tamaño exacto y lecturas parciales, y comprueba cancelación entre bloques/páginas. El caller sigue cerrando el stream.

El fallback absorbía CancellationException mediante runCatching y podía iniciar OCR después de cancelar la importación. Ahora propaga cancelación y solo recupera excepciones ordinarias. Los errores graves no se convierten en intentos OCR.
