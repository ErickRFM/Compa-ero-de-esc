# UPTlax brand usage

The official mark supplied for the project is represented by the reusable Android asset:

`apps/android/core/designsystem/src/main/res/drawable/uptlax_logo.xml`

and the composable:

`UptlaxBrand`

## Usage

Use the mark where institutional identity is meaningful:

- login / first access;
- institutional profile;
- about / institutional context;
- design-system catalog.

Do not repeat the logo on every academic card, agenda item or attendance state.

## Color

The source asset is single-color and is rendered through Compose tint:

- white/on-dark for immersive/login surfaces;
- crimson for approved brand accent contexts;
- dark/on-light only when a light institutional surface explicitly needs the mark.

The logo must not be rebuilt from plain text.
